CNC Spindle Health Monitor

A Plotly Dash floor board that turns multivariate sensor streams into per-cell health scores, TTF estimates, and maintenance notes.

This is a static project page hosted on GitHub Pages. Prefer the hosted live demo when it is available; if Streamlit/Render is asleep or unreachable, use this page and run the app locally from the repository.

Live demo (Render) ↗ Code on GitHub ↗ Portfolio ↗

Status: Portfolio learning project, not a certified CMMS / condition monitor

Challenge & trade-offs

  • Unsupervised Isolation Forest on windowed statistics — works without labeled failures and stays explainable.
  • Mock OPC-UA tag layer demonstrates IT/OT architecture; NASA CMAPSS structure remapped to CNC vocabulary.

Impact

  • 182 scored windows across a 4-machine fleet with shop-floor traffic-light thresholds.
  • One click on a cell card refreshes traces and notes; multilingual UI.

Run locally

Clone cnc-machine-health, then:

python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && python scripts/build_demo_data.py && python scripts/train_isolation_forest.py && python app.py
